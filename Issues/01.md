# List all elements used in Pokémon GO

Here's the complete list of elements and their function:
- Trainer: The avatar representing the player in the game world
  - Male/Female: Choose the own/favorite gender
  - Clothes: Personalization of the represented self within the game world
  - Name: The unique identifier of the trainer
  - Level: Main indicator for the progress of the player, points and level-based, unlocks features
  - Begin Date: The date of the day the player registered/played the first time
  - Badges: Several action statistics (for ways of progress) with bronze, silver and gold medals
- Teams: Multiple teams to cluster players into several groups based on virtues
  - Red, Blue, Yellow: Teams that can be chosen when reaching specific progress (Level 5)
- Pokédex: An overview of all received main game content (Pokémons) – once per Pokémon
  - Pokémon-Entry: Additional information on a single main game content (Pokémon)
  - Comparison: Allows for comparison between two players (also progress indicator)
  - Completable: One of the game goals is to complete the list of catched content
- Points: Indicator for progress, increased with every positive game play move
- In-Game-Currency:
  - Star Powder: Received with every catch of main game content
  - Pokémon-Candy: Counter for main game content level
- Pokémon: The main game content
  - Improvable: Powering up with specific in-game currency (star poweder + bonbons)
  - Developable: Change attack set of main game content, improve power of main game content
  - Collecting: Different types available, new types earn more points, fills Pokédex
  - Getting: Randomly appears in different places
  - List: Can be sorted by strength, id, name etc.
  - Health: Persistent defensive strength state of a main game content
  - Regions: Appears in higher/lower probability according to region on the map
- Catch: Interaction with main game content to get it
  - Ball throw: Skill-based interaction to get main game content
  - Throw-Bonusses: Better skill >> more progress points
  - Items: Different items to increase change of catching main game content
- Nearby-Pokémon: Radar to find close main-game content
  - Steps: Differenct distances for different Pokémon
  - Restriction: Maximum number of 9 elements shown
  - Unkown Content: Is being represented only by form
- Map:
  - Shows Current Position of player
  - PokéStops: Fix Places to collect free progress points from time to time (culturally interesting)
  - Gyms: Can be occupied by multiple players of same team, enemies can be fought to overtake
- Fight: Multiple main game content battles against each other
  - Avoid attack: Can decrease own damage with sill
  - Tap-to-fight: Battle though clicking and long press
  - Switch: Changing the main game content against another
- Gym:
  - Level: How well the gym was strenghened for defense, allows more pokemon if higher
  - Team: Only the pokemon of one team can be in there, until other team frees gym
  - Free gym: Anybody can take over gym
  - Restrictions: Each user can place one, maximum number defined by level
- Egg:
  - Advantage: Each and every type of main game could appear (according to probability)
  - Cost: Needs kilometers being walked
- Items:
  - Potion (Super, Hyper): Fills the persistent defensive strength of a main game content if not 0
  - Revive: Fills the persistent defensive strength to half if 0
  - Poké ball (Great, Ultra): Allows one try to get a new main game content, different probabilities
  - Lucky Egg: Doubles all points made within the game
  - Incense: Makes more main game content appear to collect nearby user
  - Lure Module: Makes more main game content appear to collect nearby Pokestop
  - Razz Berry: Increases the changes to get a main game content on next successful try
  - Egg Incubator (3x / infinite): Brings an Egg to a state where steps made are counted to hatch it
- Bag:
  - Pokemon: A list of all collected main game content, restricted to a specific amount
  - Eggs: A list with maximum of 9 Eggs to hatch
  - Items: Collection of all items, restricted to a specific amount, items deletable
  - Increasable: Pokemon and Items both can be increased by in-game currency
